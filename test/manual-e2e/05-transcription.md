# 05 文字起こし（whisper.cpp・約15分・両OS）

whisper-cli の spawn・モデル管理・3つの起動経路・オプションモーダルの実機確認。

## モデル管理

- [ ] **TRN-01 モデルのダウンロード**
  - 手順: 設定タブ「Whisper モデル」で未取得のモデル（base 等）を選択 →「ダウンロード」。
  - 期待: 進捗が見え、完了後に状態表示が「取得済み」相当になる。`native/whisper/models/ggml-*.bin` が生成される。

- [ ] **TRN-02 モデル未取得時の挙動**
  - 手順: 未取得のモデルを選んだまま文字起こしを実行。
  - 期待: わかりやすいエラー/案内が出る（クラッシュや無反応にならない）。

## 起動経路（3つ）

- [ ] **TRN-03 コマンドから（TranscribePicker）**
  - 手順: コマンド「録音ファイルを文字起こし」→ Vault 内の音声を選択。「Vault外のファイルを選択…」も1回試す。
  - 期待: どちらの経路でも文字起こしが完走する。

- [ ] **TRN-04 ファイルエクスプローラ右クリック**
  - 手順: Vault 内の音声ファイルを右クリック →「文字起こし（RMR）」。
  - 期待: オプションモーダルが開き、完走する。

- [ ] **TRN-05 埋め込み音声の右クリック**
  - 手順: ノート内の `![[録音.m4a]]` を、①ソース表示中 ②閲覧/ライブプレビューのプレイヤー上 の両方で右クリック →「文字起こし（RMR）」。
  - 期待: 両方でメニューが出る。結果が**埋め込みの直下**に挿入される。

## オプションモーダル

- [ ] **TRN-06 既存トランスクリプトの扱い**
  - 手順: 既に文字起こし済みのファイルに再実行し、「置換」「追記」「中止」をそれぞれ試す。
  - 期待: 置換=旧文が消えて新文のみ／追記=旧文の後に追加／中止=何も変わらない。

- [ ] **TRN-07 言語設定の優先**
  - 手順: 設定タブ=ja のまま、実行時モーダルで en を選んで英語音声を文字起こし。
  - 期待: 実行時の選択（en）が優先される。auto でも妥当な言語判定になる。

## 実行中の挙動

- [ ] **TRN-08 進捗表示とキャンセル**
  - 手順: 長め（5分以上）の音声で実行し、進捗(%)を確認 → 途中でキャンセル。
  - 期待: 進捗が更新される。キャンセルで whisper-cli プロセスが終了し（Activity Monitor / タスクマネージャで確認）、ノートが中途半端に書き換わらない。

- [ ] **TRN-09 停止時の自動文字起こし**
  - 手順: 「停止時に自動で文字起こし」をオンにして録音 → 停止。
  - 期待: 保存直後に自動で文字起こしが走り、埋め込みノートに結果が入る。確認後は設定を元に戻す。

## Windows 固有

- [ ] **TRN-10 非 ASCII パス（Windows のみ）**
  - 手順: 日本語ファイル名の音声（例: `会議メモ 2026-07-24.m4a`）を日本語フォルダ内で文字起こし。
  - 期待: パス起因で失敗しない（cwd をモデルディレクトリにする対策の確認）。
