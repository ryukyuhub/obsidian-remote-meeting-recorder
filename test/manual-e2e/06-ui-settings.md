# 06 UI・設定・埋め込み（約15分・両OS）

録音ビュー・設定タブ・ステータスバー・ノート連携の実機確認。

## 録音ビュー

- [ ] **UI-01 波形・メーター表示**
  - 手順: 録音ビューを開き、録音開始。発話とシステム音を鳴らす。
  - 期待: 波形/メーターが入力に追従して動く（無音時は動かない）。

- [ ] **UI-02 録音中の UI ロック**
  - 手順: 録音中に Source ラジオ・保存先・Input・Format 等を触る。
  - 期待: 録音に影響する項目が操作不可になっている（フェーダー等ライブ変更可能な項目は除く）。停止後にロック解除。

- [ ] **UI-03 タイトル入力とファイル名**
  - 手順: タイトルに日本語＋記号（例: `定例MTG 7/24 <重要>`）を入れて録音 → 停止。
  - 期待: ファイル名として不正な文字が適切に処理され、保存・埋め込みが正常に行われる。

- [ ] **UI-04 ミニ制御ウィンドウ**
  - 手順: 設定「常時前面ミニ制御ウィンドウ」をオン → 録音開始 → 他アプリ（会議アプリ想定）を前面にする。
  - 期待: ミニウィンドウが常時前面に表示され、波形が動き、停止ボタン・フェーダーが機能する。停止で閉じる。

## ステータスバー

- [ ] **UI-05 remix needed 表示**
  - 手順: mix 失敗状態（04 ROB-03 参照）を作る。
  - 期待: 通常時は非表示、失敗時のみ「⚠ remix needed」が表示され、クリックで録音ビューが開く。remix 成功後に消える。

## ノート連携

- [ ] **UI-06 埋め込み先ノートの選択（NotePicker）**
  - 手順: 録音ビューの埋め込み先ノート選択で任意のノートを指定して録音 → 停止。
  - 期待: 指定ノートに埋め込まれる。`.md` ファイル右クリック「ここに会議録音を埋め込む」でも同様に指定できる。

- [ ] **UI-07 デイリーノートにも追記**
  - 手順: 設定「デイリーノートにも追記」オンで録音 → 停止。
  - 期待: 当日のデイリーノートにも埋め込みが追記される（未作成なら作成される）。確認後は設定を戻す。

## 設定タブ

- [ ] **UI-08 保存先の切替（Vault 内 / 外）**
  - 手順: 「Vault 内に保存」をオフにして絶対パスを指定 → 録音。オンに戻して既定 `Recordings` → 録音。
  - 期待: それぞれ指定どおりの場所に保存される。Vault 外でも埋め込み・文字起こしの動線が破綻しない。

- [ ] **UI-09 状態ディレクトリの変更**
  - 手順: 「状態ディレクトリ」を別パスに変更 → 録音 → 停止。
  - 期待: 状態ファイルが新パスに作られ、録音・後始末が正常。確認後は既定に戻す。

- [ ] **UI-10 バイナリパスの「検出」ボタン（macOS）**
  - 手順: バイナリパスを空にして「検出」を押す。
  - 期待: 同梱の sysrec が自動検出される。doctor でも [OK] になる。

- [ ] **UI-11 設定の永続化**
  - 手順: 既定ソース・AGC・ミキサー等いくつか変更 → Obsidian 再起動。
  - 期待: 変更が保持され、録音ビューの初期値に反映される。
