# 07 設定の組み合わせテスト（約20分・両OS）

複数の設定が**同時に**有効なときの相互作用を確認する。全組み合わせは爆発するため、バグが出やすい相互作用をリスクベースで選んだ代表セット。

- macOS の source（sys/mic/both）× ゲインモード（AGC/オフ/手動）の全9通りは `npm run test:audio`（audio-matrix）が自動でカバー済み。ここでは耳・UI・フロー横断の組み合わせを見る。
- 各項目の末尾タグ: `[mac]` = macOS のみ / `[win]` = Windows のみ / 無印 = 両OS。

## 録音設定の組み合わせ

- [ ] **CMB-01 both × 手動ミキサー × ノイズゲート両方オン × 録音中フェーダー変更** `[mac]`
  - 手順: 手動ミキサーオン＋マイク/システム音のノイズゲート両方オンで both 録音。録音中にフェーダーを両方動かす。
  - 期待: ゲートとフェーダーが干渉せず、発話が欠けない。フェーダー変更が即時反映される。

- [ ] **CMB-02 mic × AGC × ノイズゲート** `[mac]`
  - 手順: AGC＋マイクノイズゲートオンで mic 録音。小声（ゲート閾値付近）と通常音量を交互に → 停止。
  - 期待: 小声が「ゲートで削られた後に AGC/正規化で持ち上がらない」問題がない。停止後の仕上げ正規化で聞きやすい音量になる（Issue #4 系の再発確認）。

- [ ] **CMB-03 モニター × both × AGC** `[mac]`
  - 手順: Monitor オン＋AGC オンで both 録音。スピーカー出力のまま発話。
  - 期待: モニター音がループバックに再入力されてエコー/ハウリング/AGC の暴れが起きない（起きる場合は既知の制約として記録）。

- [ ] **CMB-04 16kHz モノラル × both mix × 文字起こし** `[mac]`
  - 手順: サンプルレート 16000＋モノラル設定で both 録音 → 停止 → そのファイルを文字起こし。
  - 期待: mix・正規化・文字起こし（16kHz mono WAV 変換）まで一気通貫で正常。確認後は設定を戻す。

- [ ] **CMB-05 both × AGC × 出力デバイス切替 × 出力音量変更** `[win]`
  - 手順: AGC オンで both 録音中に、①出力音量を半分に下げる ②出力デバイスを切り替える、を続けて行う。音源は再生し続ける。
  - 期待: WIN-04 と WIN-05 が複合しても録音レベルが安定し、切替後も継続（または fail-safe でファイル確定）。

## 保存・ノート連携の組み合わせ

- [ ] **CMB-06 Vault 外保存 × 停止時埋め込み × 自動文字起こし**
  - 手順: 「Vault 内に保存」オフ（絶対パス指定）＋「停止時にノートに埋め込み」＋「停止時に自動で文字起こし」を全部オンにして録音 → 停止。
  - 期待: Vault 外ファイルでも埋め込みリンクが機能し、自動文字起こしが完走してノートに入る。

- [ ] **CMB-07 埋め込み先ノート指定 × デイリーノート追記**
  - 手順: 録音ビューで埋め込み先ノートを指定＋「デイリーノートにも追記」オンで録音 → 停止。
  - 期待: 指定ノートとデイリーノートの**両方**に埋め込まれ、内容が重複・欠落しない。

- [ ] **CMB-08 日本語タイトル × Vault 外保存 × 右クリック文字起こし**
  - 手順: タイトル `定例MTG 7/24 <重要>` で Vault 外に保存 → 保存されたファイルを「Vault外のファイルを選択…」経由で文字起こし。
  - 期待: 非 ASCII＋記号入りパスの Vault 外ファイルでも文字起こしが完走する（Windows は特に注意）。

## 堅牢性との組み合わせ

- [ ] **CMB-09 ミニ制御ウィンドウ × Obsidian 強制終了 → 復元** `[mac]`
  - 手順: ミニ制御ウィンドウオンで録音中に Obsidian を強制終了 → 再起動。
  - 期待: 録音が継続・復元され（ROB-01）、ミニウィンドウも再表示または破綻なく閉じている。停止でウィンドウが正しく片付く。

- [ ] **CMB-10 状態ディレクトリ変更 × クラッシュ → remix 復旧** `[mac]`
  - 手順: 状態ディレクトリを非既定パスに変更した状態で ROB-03（sysrec kill -9 → remix）を実施。
  - 期待: 非既定パスでも needsRemix 検出・remix 復旧が機能する。確認後は設定を戻す。

- [ ] **CMB-11 自動文字起こし中の Obsidian 終了**
  - 手順: 「停止時に自動で文字起こし」オンで録音 → 停止 → 文字起こしの進行中に Obsidian を終了 → 再起動。
  - 期待: ノートが中途半端に壊れない。録音ファイルは無事。再起動後に手動で文字起こしをやり直せる。
