## 気づき（同日対応済み・詳細は下記）

1. **設定「サンプルレート/チャンネル数」が Windows 経路の実ファイルに反映されない**: 設定は 24000Hz/モノラルだが、実ファイルは 48kHz（1本目）/44.1kHz（2本目）のステレオ。
   → **対応（f190efe）**: チャンネル数は出力段の明示ダウンミックスで反映するよう実装。サンプルレートは AudioContext 強制がループバック無音化の既知リスク（webCapture.ts のコメントに記録あり）のため実レートには反映せず、ビットレート連動である旨を設定画面に明記。
   → **実測確認（23:58 録音）**: **モノラル化 OK**（44.1kHz mono / mean −16.5dBFS で目標どおり）。
2. **ビットレートの不一致（軽微）**: 64kbps 要求に対し実ファイル 96kbps。調査の結論: Windows の MediaFoundation AAC エンコーダはビットレート下限（96kbps 付近）に丸めるため、`audioBitsPerSecond` が下限未満だと切り上げられる。
   → **実測確認（23:58 録音）**: モノラルでも 96kbps に丸められ、**サイズ削減効果は出ない**（32.5s で 405KB ≒ 前回ステレオ 406KB）。エンコーダ制約のため受容し、設定画面のモノラル説明に注記を追加して確定（サイズ削減が必要になったら webm/opus 併用を将来検討）。
3. **文字起こし品質**: base モデルのため誤認識が多め。`large-v3-turbo-q5_0` は同梱済みなので、常用するなら設定変更を推奨（未変更・ユーザ判断待ち）。
