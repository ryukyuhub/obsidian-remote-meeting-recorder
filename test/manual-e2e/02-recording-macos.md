# 02 macOS 録音（sysrec / Core Audio タップ・約20分）

sysrec バイナリ・録音経路・ミキサー・デバイスまわりの実機確認。レベル系の自動検証は `npm run test:audio`（audio-matrix）でカバー済みなので、ここでは**耳での確認と UI 連動**を中心に見る。

## ソース別録音

- [ ] **MAC-01 音源=システム音のみ**
  - 手順: 音源=system で録音、音楽/動画を20秒再生 → 停止 → 再生。
  - 期待: システム音のみが録れている（マイク音が混ざらない）。

- [ ] **MAC-02 音源=マイクのみ**
  - 手順: 音源=mic で録音、発話20秒 → 停止 → 再生。
  - 期待: マイク音のみ。停止時に仕上げ正規化が掛かり、聞きやすい音量になっている。

- [ ] **MAC-03 音源=両方（mix）**
  - 手順: 音源=both で録音、システム音＋発話 → 停止。
  - 期待: 両方の音がバランスよく混ざった1本の `.m4a`。中間ファイル（sys/mic）は削除済み。

## DRM 対策（Core Audio タップ移行の検証）

- [ ] **MAC-04 DRM 動画再生中の録音**
  - 手順: Netflix / Amazon Prime 等の DRM 保護動画を再生した状態で録音開始 → 20秒 → 停止。
  - 期待: **動画の画面が黒くならない**（Core Audio タップ移行の主目的）。録音を開始しても再生が中断されない。
  - 注: DRM 音声そのものが録れるかは環境依存。画面が黒くならないことが合格ライン。

## ミキサー・ゲイン

- [ ] **MAC-05 AGC オン**
  - 手順: 「音量の自動調整（AGC）」オンで both 録音。小声と大声、音量の大小ある動画を混ぜる → 停止。
  - 期待: 停止後のファイルが目標ラウドネス近傍（極端な音量差が均されている）。

- [ ] **MAC-06 手動ミキサー・録音中ライブ反映**
  - 手順: 手動ミキサーをオンにし、録音**中**にシステム音/マイクのフェーダーを動かす（例: マイク +6dB → -12dB）。
  - 期待: 波形/メーター表示と録音物の両方に**録音中の変更が即時反映**される（control ファイル経由）。

- [ ] **MAC-07 ノイズゲート**
  - 手順: 「マイクのノイズゲート」オンで mic 録音。無音区間と発話を交互に → 停止。
  - 期待: 無音区間のホワイトノイズ/環境音が抑えられ、発話は欠けない。

## デバイス

- [ ] **MAC-08 入力デバイス選択**
  - 手順: 録音ビューの Input で内蔵マイク以外（外付け/AirPods等）を選択して録音。
  - 期待: 選択したデバイスで録れている。設定「既定の入力デバイス」も次回起動時に反映される。

- [ ] **MAC-09 録音中の出力デバイス切替**
  - 手順: both 録音中にシステムの出力デバイスを切り替える（スピーカー→AirPods等）。音を鳴らし続ける。
  - 期待: 切替後もシステム音の録音が継続する（ログに再接続の記録）。2026-07-24 の実障害の回帰確認。

- [ ] **MAC-10 モニター（試聴）**
  - 手順: Monitor チェックをオンにして録音。
  - 期待: 自分のマイク音が出力から聞こえる。録音物にモニター起因のエコー/ループが入らない。

## その他

- [ ] **MAC-11 無音ウォッチ**
  - 手順: 音源=mic でマイクをミュート（または物理的に無入力）にして録音開始。
  - 期待: 開始10秒で「無音」の通知が出る。**録音自体は継続**する。

- [ ] **MAC-12 ファイル名衝突**
  - 手順: 同じタイトルで2回連続録音。
  - 期待: 2本目が `-2` 連番で保存され、1本目が上書きされない。

- [ ] **MAC-13 録音中のスリープ抑止**
  - 手順: 録音中に電源設定のスリープ時間を短くして放置（または長時間録音）。
  - 期待: 録音中はスリープしない（caffeinate）。停止後は通常どおりスリープする。

- [ ] **MAC-14 サンプルレート/チャンネル設定**
  - 手順: 設定でサンプルレート 16000 / モノラルに変更して録音 → 停止。
  - 期待: 指定どおりのフォーマットで保存される（`afinfo <file>` で確認）。確認後は既定値に戻す。
