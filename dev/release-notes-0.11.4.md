## 0.11.4

Windows の診断（doctor）を強化する小さなリリースです（[#8](https://github.com/ryukyuhub/obsidian-remote-meeting-recorder/issues/8) の補完）。

### 追加

- **診断（doctor）に「Smart App Control」の状態検査を追加**（Windows）。0.11.3 で whisper を実際に起動してブロックを検出するようにしましたが、スマート アプリ コントロールには **exe の起動は許しつつ、内部の DLL（ggml-cpu-*.dll）の読み込みだけを止める**動き方もあります。その場合、診断は [OK] のまま OS の警告ポップアップだけが出続け、文字起こしは失敗・低速化しえました（実機の CodeIntegrity イベント 3033/3077 で確認）。本リリースからレジストリ（`VerifiedAndReputablePolicyState`）で SAC の状態を直接読み、**強制モードなら起動可否に関わらず [WARN]** と解除手順・Microsoft の案内ページへのリンクを表示します（評価モード= INFO、オフ / 非搭載 = OK）。録音自体には影響しません。
  - 補足: スマート アプリ コントロールに除外リストは無く、個別のアプリだけ許可することはできません。2026-04 より前の Windows では一度オフにすると元へ戻せない場合があるため、案内文にもその旨を明記しています。

### 内部

- `sysrec` バイナリの変更はありません（abi 2 のまま）。**0.11.1 以降から更新する方はバイナリの入れ替え不要**です。
