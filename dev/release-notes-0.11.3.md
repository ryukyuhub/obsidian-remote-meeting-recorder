## 0.11.3

Windows で報告された 3 件（[#8](https://github.com/ryukyuhub/obsidian-remote-meeting-recorder/issues/8) / [#9](https://github.com/ryukyuhub/obsidian-remote-meeting-recorder/issues/9) / [#10](https://github.com/ryukyuhub/obsidian-remote-meeting-recorder/issues/10)）の修正です。

### 修正

- **録音中にフェーダーを動かしても録音レベルが変わらない問題を修正**（Windows・[#10](https://github.com/ryukyuhub/obsidian-remote-meeting-recorder/issues/10)）。仕上げの自動レベル調整が手動ミキサー中も動いており、**フェーダーを上げたぶんを打ち消して**いました。録音開始からの累積の音量を一定の目標へ寄せ続ける仕組みのため、手で上げても元の大きさへ戻されていたものです。手動ミキサー中は自動レベル調整を止め、フェーダーの操作をそのまま録音に反映します。
  - macOS はこの問題を持ちません（停止後に全体へ同じゲインを掛ける方式のため、録音中の増減はそのまま残ります）。実測: 録音中に +18 dB → 録音ファイルが -30.1 dB → -12.9 dB。
- **ミニ制御ウィンドウのレベルメーターが、別の仮想デスクトップ（macOS は別 Space）や背面で止まる問題を修正**（[#9](https://github.com/ryukyuhub/obsidian-remote-meeting-recorder/issues/9)）。会議アプリを前面にすると Obsidian が背面になり、**Chromium がメーターの更新を毎秒 1 回まで絞る**うえ、見えていないウィンドウでは描画そのものが呼ばれなくなっていました。ミニ窓を開けている間だけ抑制を解除し、描画をタイマー駆動に変えました（閉じると元に戻します）。
  - 実測（macOS・Obsidian が背面のとき）: 66ms 間隔の更新が **1 Hz → 15 Hz**。
- **文字起こしが Windows のセキュリティ機能にブロックされたとき、何が起きたか分かるようにしました**（[#8](https://github.com/ryukyuhub/obsidian-remote-meeting-recorder/issues/8)）。同梱の whisper.cpp はコード署名が無いため、**スマート アプリ コントロール**が有効な Windows 11 では起動を止められます。従来は OS の警告ポップアップと `exit 3221226024` という追跡不能なメッセージが 10 秒で消えるだけでした。
  - **診断（doctor）が実際に whisper を起動して確認する**ようになりました。ファイルがあるだけでは OK にせず、ブロックされていれば **NG** と解除手順を出します（会議のあとではなく事前に気づけます）。
  - 失敗したときは**消えない通知**で「録音は保存済みです」「解除後に音声ファイルを右クリック →『文字起こし』でやり直せます」「解除手順」を案内し、**「録音後の自動文字起こしをオフにする」ボタン**を添えました（解除しない場合に録音のたびポップアップが出るのを止められます）。
  - whisper の必要な DLL が無い場合も切り分けて案内します（再取得を促します）。

### 変更（挙動が変わります）

- ⚠️ **Windows で手動ミキサーを使う場合、録音の音量が自動で持ち上がらなくなりました。** フェーダーの値がそのまま録音レベルになるため、小さい設定のままだと小さく録れます。音量を自動で整えたい場合は**手動ミキサーをオフ（Auto gain）**にしてください。クリップ（歪み）防止のリミッターは手動モードでも従来どおり常時効きます。
- 録音ビューの注記を「自動ゲインは無効」→「自動のレベル調整は無効」に変更しました。

### 内部

- `sysrec` バイナリの変更はありません（abi 2 のまま）。**0.11.1 以降から更新する方はバイナリの入れ替え不要**です。
- Windows の実行ブロック判定を `src/util/winBlock.ts` に切り出し、**Windows 実機なしで回帰を検出できるよう** E2E に 12 項目を追加（合計 101 件）。ブロックの現れ方は 2 通り（CreateProcess の失敗＝Node からは `UNKNOWN` ／出力ゼロのまま `STATUS_INVALID_IMAGE_HASH` 等で即終了）で、どちらも拾います。
- 設計書 §9.4（ミニ窓が背景化に負けない作りにする根拠）・§15.5（whisper は存在だけで OK にしない）、「Windows対応 実装計画」に W5 を追記。
- 手動 E2E に **UI-04b**（背面・別デスクトップでメーターが動く）・**UI-04c**（録音中のフェーダーが録音に反映される）・**TRN-11**（スマート アプリ コントロールでのブロック）を追加。
