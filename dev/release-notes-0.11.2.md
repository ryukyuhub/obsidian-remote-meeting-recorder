## 0.11.2

### 改善

- **録音ビューの UI が窮屈で操作しにくい問題を改善**（[Issue #7](https://github.com/ryukyuhub/obsidian-remote-meeting-recorder/issues/7)）。設定項目が増えるにつれて 12 行が同じ間隔で並び、どれも押しにくくなっていました。
  - **「録音設定 / 音量 / 詳細設定」の 3 グループに整理**しました。めったに変えない項目（マイクゲート・システムゲート・形式・ミニ制御窓・Whisper）は「詳細設定」にまとめ、**既定は折りたたみ**です。常時見えるのは 7 行になりました。
  - **本文ペインで開いても中身が中央の 1 カラム（最大 620px）に収まる**ようにしました。従来は横幅いっぱい（1000px 超）にコントロールが間延びし、ラベルと入力欄が遠く離れていました。
  - **狭いサイドバー（400px 未満）ではラベルを各行の上に積む**ようにしました。項目名と入力欄がぶつかって潰れません。
  - 行間・行の高さ・録音/停止ボタンを広げ、**チェック項目は説明文のどこを押しても切り替わる**ようにしました（従来は小さな四角しか反応しませんでした）。
- **録音ビューの項目名を日本語に統一**しました（Source → 音源、Save to → 保存先、Input → 入力、Monitor → 試聴、Format → 形式、Auto gain → 自動ゲイン）。「自動ゲイン」には説明文（小さすぎる声を自動で持ち上げる）を添えました。

### 修正

- **録音ビューを本文ペインとサイドバーに同時に開くと、片方の「音源」の選択が消える問題を修正**しました。2 つのビューのラジオボタンが同じグループ名を共有していたためで、ビューごとに独立させました。

### 内部

- `sysrec` バイナリの変更はありません（abi 2 のまま）。**0.11.1 から更新した方はバイナリの入れ替え不要**です。
- 設計書 §9.1（録音ビューのモック・コントロール対応表）を新しい構成に更新。
- 手動 E2E に **UI-02b**（レイアウト: 本文ペイン／サイドバー・詳細設定の開閉・説明文クリック・ラジオの独立）を追加し、チェックリストの項目名を新しい UI 文言に合わせました。
