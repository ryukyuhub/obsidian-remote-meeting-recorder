## 0.10.0

### 修正（重要）

- **長時間録音の保存が終わらない問題を修正**。mix / normalize が録音全体を 1 回の `AVAudioFile.write(from:)` に渡していたため、AAC エンコーダ内部の処理時間が長さに対して急激に伸びていた。実測で **73 分の録音は 20 分以上 CPU を回しても書き終わらず**、10 秒ごとの分割書き出しに変えたところ **同じ素材が 11 秒で完了**するようになった。
  - これが「保存が完了しなかった録音」が発生する主因だった。mix の最中に Obsidian を終了すると、`moov` アトムを欠いた**再生できない m4a** が残る（実際に 73 分の会議録音が 1 件この状態になっていた。中間ファイルから復旧済み）。
  - ⚠️ 同梱の `sysrec` は CI（macOS ランナー）で本タグからビルドされるため修正済み。**既存の Mac 環境は doctor の「sysrec を取得」または `npm run build-sysrec` で更新してください。**
- **復旧待ちの録音が 2 件以上あると 1 件しか復旧できない問題を修正**。復旧対象を単一スロットで保持していたため、起動時のループで上書きされ、2 件目以降が UI から辿れなくなっていた。
- 起動時に復旧待ちを検出したとき、ステータスバーの警告が出ていなかったのを修正（数秒で消える通知だけが手がかりだった）。

### 変更

- **会議録音画面から主要設定を直接変更できるようにした**（Issue #5）。設定タブを開かずに録音の直前・最中に調整できる。設定画面とは双方向に同期する。
  - マイク／システム音のノイズゲート（macOS・Auto gain 有効時のみ表示。sysrec 起動時の引数のため録音中はロックされ、次の録音から反映）
  - 常時前面ミニ制御ウィンドウ（録音中に切り替えるとその場で開閉）
  - Whisper モデル（未取得なら注意を表示）
- **「remix 復旧」を分かる言葉と導線に置き換えた**（Issue #6）。「remix」という内部用語では何が起きたのか・何をすればいいのかが伝わらなかった。
  - 文言を「録音の保存が最後まで終わりませんでした。音声は残っているので復旧できます」に変更
  - 通知に「録音を復旧する」ボタンを追加。コマンド名を知らなくても押すだけで復旧できる
  - 録音ビュー上部に復旧バナーを常設（通知は数秒で消えて手がかりが残らないため）
  - 対象の録音を日時・長さ付きで表示（例「2026-07-25-1318（2026-07-25 13:18・1時間13分）」）
  - コマンド名を「保存が完了しなかった録音を復旧」に変更（ホットキー互換のためコマンド ID は据え置き）
  - 素材が残っておらず本当に復旧できない失敗は区別し、消えない警告を残さないようにした

### 開発・品質

- 録音ビューが複数開かれているとき、最後に開いた 1 つにしか経過時間・終了イベント・再描画が届いていなかったのを全ビューへ通知するよう修正。
- Whisper のモデル選択肢と既定モデル名が 4 ファイルに重複していたのを共有定数に一本化。
- 手動 E2E チェックリストに復旧まわりの項目を追加（復旧待ち 2 件の個別復旧、長時間録音の mix 完了）。
